## performance-report 数据加工时机修复（commit 349fcc2）

- **症状**：爬虫离线时打开绩效面板无数据（用户误判为降级逻辑失效）。
- **根因**：组件经 uiStore 动态沙箱常驻挂载后，onMounted 仅执行一次且早于数据就绪（reportData 仍为空），processData 在空数据上运行；此后 show=true 只切换 v-if 显隐、不重新挂载，processData 永不重跑 → 面板空白。
- **教训**：**uiStore 常驻挂载的组件（root v-if 控制显隐）不能依赖 onMounted 处理数据**，须用 watch(store 显隐开关) 在打开后重跑数据加工；「先拉数据 → 后开窗」时序依赖此保障。
- 降级逻辑本身在 FactoryService.fetchMonthlyOutput（useLocal=false 走宿主接口）未受重构影响。
- 修复：watch(reportStore.show) → nextTick → processData()。验证：tsc + build 通过。
