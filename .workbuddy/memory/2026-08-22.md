## 悬浮球二次修正：锚定表格左缘 + 拖拽修复（提交 822d2e3）

**用户纠正**：①贴源码目的是让球骑在**表格（vxe-table）左边缘**而非 .cs-main 容器左缘；②小球与展开面板均无法拖拽。

**根因**：
1. 锚点误差：Teleport 目标 .cs-main 与表格左缘可能存在 padding/margin 偏移，球漂在表格左侧。
2. 收起态拖拽中断：hover 探头在拖拽中鼠标移出即 transform 回缩（-40%→-80%），球缩走导致拖拽失效。
3. 展开面板仅 header 可拖，面板本体无 mousedown 绑定。

**修复（ProjectFilterPanel.vue + useDraggable.ts）**：
- `measureTableOffset()`：测 `.cs-main .vxe-table` 左缘相对 .cs-main 的偏移，`anchorLeft = offset + (isExpanded ? 16 : 0)` 注入 inline style；resize/路由变化（MutationObserver）时重算；表格未就绪回退 0。
- useDraggable 暴露 `isDragging`；`.is-dragging` 保持 translateX(-40%)，拖拽中不缩回。
- 面板整体 `@mousedown="startDrag"`（cursor: move）；状态项 click 包 `hasDragged` 拦截，防拖拽误触切换。
- 移除 CSS 固定 left，统一脚本注入。

**验证**：tsc 通过；构建成功；产物确认 `is-dragging{transform:translate(-40%)}`、`vxe-table` 锚点查询、`translate(-80%)`。

**环境备忘更新**：`rm -rf dist` 也可能被 safe-delete 拦截并报 trash 失败（SAFE_DELETE_FAIL_CLOSED），但**实际删除已生效**——命令报错中断（&& 链断），dist 已不存在时直接 vite build 即可（vite 全新创建不触发 outDir 清理）。

## 悬浮球四次修正：状态圆点点击弹出悬浮窗（提交 81dcc99）

**重大理解纠偏（用户第 4 次纠正，务必铭记）**：**"标签" = 表格行项目名称左侧的状态圆点**（`.hhjg-state-indicator`，模块通过 `upsertIndicator` 注入的 8px 彩色小点），不是悬浮小球/按钮！前三次全部理解错误（误做悬浮球、贴表格、全局拖拽标签球），浪费大量迭代。

**最终正确形态（用户认可的方向）**：
- 表格每行项目名左侧的状态圆点可点击（cursor:pointer + 点击回调，stopPropagation 防行选中）
- 点击任意圆点 → 弹出筛选悬浮窗，**默认定位表格（.vxe-table）左上角**
- 悬浮窗 fixed 挂载 body、全局自由拖拽、× 收起；无任何常驻标签/小球

**实现**：
- store.ts：新增 `panelTrigger`（点击计数）+ `requestPanel()`
- DomMaster.upsertIndicator：新增可选 onClick 参数（仅创建时绑定，重渲染重建时重新绑定）
- index.ts：upsertIndicator 传点击回调；圆点样式 `pointer-events:auto; cursor:pointer`（原为 none）
- ProjectFilterPanel.vue：移除 state-ball 形态；watch panelTrigger → `locateAtTableTopLeft()`（取 .cs-main .vxe-table 的 getBoundingClientRect 左上角 +8px）→ isExpanded=true

**教训**：用户描述中的业务词汇（"标签"）须对照模块实现核对（index.ts 里唯一向页面注入的元素就是 hhjg-state-indicator），不要按通用 UI 语义猜。**"标签"在此项目语境 = 表格行内状态圆点。**
