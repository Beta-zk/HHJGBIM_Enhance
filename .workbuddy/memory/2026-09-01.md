# 2026-09-01 工作日志

## project-state 字典源切换：GetEntities → GetDictionaryDetailListByCode（commit 274de0a）

**背景**：用户发现更简洁的字典接口，替代旧 PLM 项目实体分页接口。

**新接口**：`https://integ-plat-api.bimtk.com/Platform/Dictionary/GetDictionaryDetailListByCode`
- 请求：POST + JSON body `{"dictionaryCode": "project_status"}`（凭证走 postWithAuth 自动携带）
- 响应：`{ Data: [...] }`，Data 直接是对象数组（旧接口为分页嵌套结构）；字段与旧接口一致（Name / Project_Name / Short_Name / State_Name）

**改动三处**：
1. `constants.ts`：新增 `PLM_PROJECT_DICTIONARY`；旧 `PLM_PROJECT_ENTITIES` 整行注释停用（[备用] 标注）。
2. `ProjectService.ts`：新增 `PROJECT_STATUS_DICT_CODE = 'project_status'`；旧分页载荷 `defaultPayload` 与旧接口调用整体注释停用（[备用] 标注）；新请求走 `postWithAuth(PLM_PROJECT_DICTIONARY, { dictionaryCode })`。
3. `project-state/index.ts` `buildDictionary`：非爬虫分支解析由 `plmJson.Data?.Data` 改为 `plmJson.Data`（新接口 Data 直接是数组）；爬虫分支兜底链自动兼容无需改。

**验证**：tsc 通过；dist 重建成功（47 模块，137.57 kB）；产物 grep 确认旧 URL `GetEntities` 零残留、新接口与 dictionaryCode 生效。

**待真机验证**：项目列表页字典预热与状态圆点/筛选功能正常。

## 修正：状态字段 Display_Name + 常量名泛化（commit fd20291）

**用户更正**：新字典接口返回对象中状态字段实际为 `Display_Name`（非 State_Name）；且该接口为**通用字典接口**，请求体携带任意 dictionaryCode 可请求任意字典，常量命名不应限定项目专用。

**改动**：
1. `project-state/index.ts`：状态字段读取改为 `item.Display_Name || item.State_Name || '未知'`——Display_Name 供新字典接口，State_Name 兜底兼容本地爬虫数据源（useLocal 分支仍返回旧字段）。
2. `constants.ts`：`PLM_PROJECT_DICTIONARY` 更名为 `GET_DICTIONARY_DETAIL_LIST_BY_CODE`（通用语义，与 GET_COMP_SCHDULING_PAGE_LIST 等命名风格一致）。
3. `ProjectService.ts`：引用同步更新。

**验证**：tsc 通过；dist 重建成功（47 模块，137.61 kB）；产物确认新常量名、Display_Name 与 dictionaryCode 生效，旧命名零残留。

## 修复：@connect 白名单缺新字典域名（commit 87a359a）

**症状**：控制台报 `Refused to connect to "https://integ-plat-api.bimtk.com/...": This domain is not a part of the @connect list`，字典预热失败。

**根因**：油猴 GM_xmlhttpRequest 仅允许请求 `userscript.connect` 登记域名；新字典接口域名 `integ-plat-api.bimtk.com` 未登记（原列表只有 proj/produce/127.0.0.1）。

**修复**：`vite.config.ts` connect 数组首位登记新域名 + 注释说明用途；旧 `integ-plat-proj-api.bimtk.com` 标注 [备用] 保留（旧接口回退仍可用）。meta.js 确认 `@connect integ-plat-api.bimtk.com` 生效。

**⚠️ 生效前提**：@connect 为脚本安装期元数据，**必须重新安装/更新脚本**（覆盖安装新 user.js）才会生效，仅刷新页面无效。
