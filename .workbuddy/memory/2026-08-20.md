## DomService → core/DomMaster 升级（同日二次重构，构建验证通过）

**需求**：DomService 定位为通用 DOM 工具，迁入 core 包改名 DomMaster，由 main 默认激活，路由变化时缓存页面情报（含结构树），暴露「内容归属结构树」通用查询接口；全项目 JSDoc/log 清洗。

**改动**：
- 删除 `src/services/DomService.ts`，新建 `src/core/DomMaster.ts`（单例 `domMaster`，同 NetworkHook 风格）。
- 新增能力：`init()`（main 激活）、SPA 路由监听（hashchange/popstate/history pushState/replaceState 钩子 + URL 变更检测）、路由变化 400ms 防抖重扫、`refresh()`/`getSnapshot()`/`onRouteChange()`、页面快照（URL/标题/面包屑/结构树）、`scanStructureTrees()`（自动探测 .el-tree/.ant-tree/.ep-tree/[role=tree] 树容器与节点选择器，清洗节点文本构建 text→path 索引）、`findInStructureTrees(text, {partial?})`（归属查询，返回节点及 path 归属链）。
- 通用性原则：查询接口只做「按文本找归属路径」；调用方复杂需求（如选中/展开树节点）自行实现，不往 DomMaster 塞专用方法。
- main.ts 激活顺序：NetworkHook → domMaster → authService → 各 Enhance。
- 注释/log 清洗：保留每模块就绪日志 + 错误/诊断日志 + 关键业务结果日志；删除过程日志（如级联成功、样式修正完毕）；core 各模块补方法级 JSDoc；services 中 SystemService/ProjectService/FactoryService 的 class/method 描述精确化；helpers 迁移说明更新为 core/DomMaster。

**验证**：`tsc --noEmit` 通过；`vite build` 产出 dist/HHJGBIM_Enhance.user.js (121.48 kB)，产物含 DomMaster/findInStructureTrees/scanStructureTrees 符号。
